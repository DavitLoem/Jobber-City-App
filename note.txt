១. ផ្នែក Data Models (អ្នកទទួលទិន្នន័យ)
យើងមិនអាចយកទិន្នន័យ JSON មកប្រើផ្ទាល់ៗបានទេ យើងត្រូវបង្កើត Model ថ្មីមួយសម្រាប់ចាប់យក Response ពី API upload-cv។

អ្វីដែលត្រូវបង្កើត៖ CvExtractionResponseModel, ParsedExperienceModel, ParsedEducationModel, និង ParsedSkillModel។

តួនាទី៖ បំប្លែង JSON ទៅជា Object ងាយស្រួលឱ្យសរសេរកូដនៅខាង Controller (មាន Auto-complete មិនងាយសរសេរខុស)។

២. ផ្នែក Controller (ខួរក្បាលបញ្ជា)
យើងមិនគួរសរសេរ Logic នេះចូលក្នុង Profile Controller ចាស់ទេ វាអាចធ្វើឱ្យកូដវឹកវរ។ យើងគួររៀបចំ Controller ថ្មីមួយដាច់ដោយឡែក។

អ្វីដែលត្រូវបង្កើត៖ CvSmartFillController (ឬឈ្មោះអ្វីក៏បានតាមអ្នកចូលចិត្ត)។

៣. ផ្នែក UI Flow (លំហូរអេក្រង់ទាំង ៣ ដំណាក់កាល)
នេះជាបទពិសោធន៍ប្រើប្រាស់ (UX) ដែលយើងត្រូវរៀបចំ៖

ដំណាក់កាលទី ១ (Trigger): ប៊ូតុង "Upload CV (Auto-fill)" ដ៏ទាក់ទាញមួយនៅលើអេក្រង់ Profile របស់ Seeker។

ដំណាក់កាលទី ២ (Scanning Overlay): ពេលកំពុង Upload និងរង់ចាំ AI គិត យើងមិនបើកអេក្រង់ថ្មីទេ តែយើងប្រើ Get.dialog() បង្ហាញផ្ទាំង Loading វិលៗ ឬ Lottie Animation (រូបរ៉ាដា) ជាមួយអក្សរ "AI is analyzing your CV..." ដើម្បីកុំឱ្យគាត់ចុចអ្វីផ្សេងបាន។

ដំណាក់កាលទី ៣ (Result BottomSheet): ពេល AI បោះទិន្នន័យមកវិញ យើងបិទ Dialog នោះ ហើយលោត BottomSheet បញ្ជាក់ថា៖ "ជោគជ័យ! យើងរកឃើញបទពិសោធន៍ (៣) និងការអប់រំ (២)។ តើអ្នកចង់ពិនិត្យមើលវាទេ?" បើគាត់ចុច "Review" ទើបយើងរុញគាត់ (Get.to) ទៅអេក្រង់បន្ទាប់។
